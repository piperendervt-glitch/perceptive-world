# world.md — Ordia の世界設定

書込許可: editor のみ。
TIER: 1（常時参照）。

## 基本

- ジャンル: 異世界転生ファンタジー。
- 魔法は一般的に使える技術として社会に組み込まれている。
- 魔法の強さは血統（血の濃さ）に強く相関する。強い家系ほど強力な魔法を継承する。
- そのため、強い血統の家系が王族・貴族として政治的地位を得ている。
- 種族・モンスターは定番構成（人族／エルフ／ドワーフ／獣人／竜族／魔物 等）が各地に住む。
- 転生者は複数人存在する。互いに面識のある者・ない者が混在する。

## 「理（ことわり）」

- 世界の根本法則を「理」と呼ぶ。
- **何者も理から外れることはできない**。神も王も転生者も例外ではない。
- 「理を破る」ことは物理的にも社会的にも不可能で、試みた者には必ず対価が返る。
- 対価は「その者がこの世界に存在するために依っているもの」の毀損として現れる（後述: 情報格差／代償の項）。

## ステータス（数値）

- レベル・スキル・属性値などの数値情報は**転生者にしか見えない**。
- 現地人（生まれつきこの世界の住人）にはステータスは知覚できない。存在も認識されていない。
- 転生者はこの数値を頼りに判断・成長を最適化できるが、**それは同時に「知ってしまった者」の孤立を意味する**。
- ステータスは便利表示ではなく、**知識の格差＝呪い**として扱う。ここが劇的アイロニーの主装置。

## 転生の性質

- 転生者は前世（現代日本相当）の記憶を保持している。
- 転生の経緯は本人にとっても不明。「気づいたら転生していた」以上のことは分からない。
- 転生者同士は、互いを見分ける手段を初期状態では持たない（ステータス干渉や特定条件下でのみ判定可能）。

## 地理・時代感

- 中世〜近世相当の技術水準。魔法によって局所的に近代インフラ相当が実現している場所もある。
- 大陸は複数の王国・自治領・種族領域に分かれ、中心部に古代遺跡群が点在する。
- 遺跡は「理」に関する記録を断片的に含む。断片は各地に散る（詳細は central_question.md）。
