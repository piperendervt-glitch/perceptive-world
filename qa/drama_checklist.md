# drama_checklist.md — ドラマQA（面白さの検査）

書込許可: qa（このファイル自体は editor 管轄。qa は qa/reports/ のみ書込可）。
TIER: 1（常時参照）。

## 判定区分

- **Blocker**: canon 登録不可。
- **Major**: 登録前に修正推奨。
- **Minor**: 記録のみ。
- **Warning**: 蓄積で Major に昇格。

## チェック項目

### D-1. 価値の反転（ターン）

- [ ] このシーン／話に、価値の反転が最低1つあるか（[[drama_invariants]] I-D1）
  - なし → **Major**
  - 2話連続でなし → **Blocker**
- [ ] 反転は仕込み（伏線・状況）から必然に見えるか
  - 唐突すぎ／偶然に頼る → **Major**

### D-2. 緊張の緩急

- [ ] 前話と比較して tension が変化しているか（I-D3）
  - 同値のまま → **Warning**
  - 3話連続で同方向の変化 → **Warning**（4話連続なら **Major**）
- [ ] 上げる話には局所的な緩み、下げる話には局所的な引きがあるか
  - 単調上昇／単調下降 → **Warning**

### D-3. 中心の問い

- [ ] 中心の問い（[[central_question]]）は開いたままか（I-D2）
  - 全部閉じた → **Blocker**
  - 主要な問いが早期に閉じた → **Blocker 級 Major**
- [ ] 新しい問いが最低1つ開かれたか
  - なし → **Major**

### D-4. 感情の示し方

- [ ] 感情を地の文で説明していないか（I-D4）
  - 「彼は悲しかった」等の直接説明多用 → **Minor**（頻発なら **Major**）
- [ ] 会話に subtext（建前と本音のズレ）があるか
  - 全て建前で言い切っている → **Minor**

### D-5. 「得た＝失った」の代償

- [ ] 主人公が秘密／理に近づいた話で、何かを失っているか（I-D5）
  - 失っていない → **Blocker**
- [ ] 失ったものは、単なる物理的損失ではなく、want/need/lie に触れているか
  - 表面的損失のみ → **Major**

### D-6. 対立ウェブの維持

- [ ] 対立を「話し合いで解消」していないか（I-D6）
  - 解消済み → **Major**
- [ ] 同盟が成立した場合、第三者に対する犠牲が発生しているか（[[conflict_web]] 三角関係の構造化ポイント）
  - 全員救済ルートを許容 → **Blocker**

### D-7. 情報格差

- [ ] 転生者⇔現地人のステータス可視性の格差は維持されているか（I-D7）
  - 埋めた／埋めかけて代償なし → **Major**
- [ ] 読者と登場人物間の情報差（劇的アイロニー）が最低1箇所で機能しているか
  - なし → **Minor**（連続でなしなら **Major**）

### D-8. open_loops 台帳との整合

- [ ] 敷設された伏線・問いは [[open_loops]] に追加されているか
  - 未追加 → **Major**
- [ ] 3話連続で触れていない promise_to_reader=true の項目はないか
  - あり → **Warning**
