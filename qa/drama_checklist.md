# drama_checklist.md — ドラマQA（面白さの検査）

書込許可: qa（このファイル自体は editor 管轄。qa は qa/reports/ のみ書込可）。
TIER: 1（常時参照）。

## 判定区分

- **Blocker**: canon 登録不可。
- **Major**: 登録前に修正推奨。
- **Minor**: 記録のみ。
- **Warning**: 蓄積で Major に昇格。

## チェック項目

### D-1. 価値の反転（ターン）

- [ ] このシーン／話に、価値の反転が最低1つあるか（[[drama_invariants]] I-D1）
  - なし → **Major**
  - 2話連続でなし → **Blocker**
- [ ] 反転は仕込み（伏線・状況）から必然に見えるか
  - 唐突すぎ／偶然に頼る → **Major**

### D-2. 緊張の緩急

- [ ] 前話と比較して tension が変化しているか（I-D3）
  - 同値のまま → **Warning**
  - 3話連続で同方向の変化 → **Warning**（4話連続なら **Major**）
- [ ] 上げる話には局所的な緩み、下げる話には局所的な引きがあるか
  - 単調上昇／単調下降 → **Warning**

### D-3. 中心の問い

- [ ] 中心の問い（[[central_question]]）は開いたままか（I-D2）
  - 全部閉じた → **Blocker**
  - 主要な問いが早期に閉じた → **Blocker 級 Major**
- [ ] 新しい問いが最低1つ開かれたか
  - なし → **Major**

### D-4. 感情の示し方

- [ ] 感情を地の文で説明していないか（I-D4）
  - 「彼は悲しかった」等の直接説明多用 → **Minor**（頻発なら **Major**）
- [ ] 会話に subtext（建前と本音のズレ）があるか
  - 全て建前で言い切っている → **Minor**

### D-5. 「得た＝失った」の代償

- [ ] 主人公が秘密／理に近づいた話で、何かを失っているか（I-D5）
  - 失っていない → **Blocker**
- [ ] 失ったものは、単なる物理的損失ではなく、want/need/lie に触れているか
  - 表面的損失のみ → **Major**

### D-6. 対立ウェブの維持

- [ ] 対立を「話し合いで解消」していないか（I-D6）
  - 解消済み → **Major**
- [ ] 同盟が成立した場合、第三者に対する犠牲が発生しているか（[[conflict_web]] 三角関係の構造化ポイント）
  - 全員救済ルートを許容 → **Blocker**

### D-7. 情報格差

- [ ] 転生者⇔現地人のステータス可視性の格差は維持されているか（I-D7）
  - 埋めた／埋めかけて代償なし → **Major**
- [ ] 読者と登場人物間の情報差（劇的アイロニー）が最低1箇所で機能しているか
  - なし → **Minor**（連続でなしなら **Major**）

### D-8. 情報格差の装置化（形骸化検査）

D-7 が「格差の存在維持」を問うのに対し、D-8 は「格差がこの話で装置として動いたか」を問う。存在するだけでは足りない。

- [ ] 転生者だけが数値を見る非対称が、この話で装置として動いているか
  - 動いた例: H が数値ゆえに躊躇／隠す／独りで抱える／現地人との溝を感じる／他の転生者との連携や駆け引きで数値が意味を持つ、など
  - 動かず「H の内語に数値が出るだけ」 → **Warning**（形骸化）
  - 2話連続で動かない → **Major**

### D-9. open_loops 台帳との整合

- [ ] 敷設された伏線・問いは [[open_loops]] に追加されているか
  - 未追加 → **Major**
- [ ] 3話連続で触れていない promise_to_reader=true の項目はないか
  - あり → **Warning**

### D-clarity. 明瞭さ（曖昧さの帰属）

CL1 の [[drama_invariants]] I-D8 / I-D9 を検査可能にする。**詩的であること自体は減点しない**。
曖昧さが「どこに配分されているか」だけを見る。ハイブリッド構成（道A）: コードが曖昧さ候補を
機械抽出し（`qa_deterministic.extract_ambiguity_candidates`。抽出のみ・判定しない）、意味判断が
open_loops 照合で仕分ける（Claude Code セッション内）。

- [ ] このシーンの「わざと不明な表現」が、[[engine_state]] の open_loops に登録された謎に紐づくか（I-D8）
  - 登録された謎に**直接紐づく**曖昧さ → **通過**（意図した謎）
  - 紐づかない曖昧表現（指示対象不明・主観／客観不明・字義が壊れた比喩）→ **Warning**
    （writer に「謎に紐づける」か「明快にする」を選ばせる。常態化していれば I-D8 に沿って Major へ）
- [ ] 超常描写に主観／客観の帰属が読めるか（I-D9）
  - 主観マーカー（"ように" / "見えた" / "気がした" / "映った" 等）で H の知覚と読める → **通過**
  - 帰属不明の超常（主観マーカーがなく、客観としても [[invariants]] 非適合）→ **Warning**
    （客観として理を破る事象を事実化していれば I-D9 に沿って Blocker）
- 抽出候補の種別（`meta.kinds`）: `missing_referent`（指示対象/目的語の欠落）,
  `literal_breaking`（字義が壊れる慣用・比喩）, `supernatural`（超常/擬人化。`has_subjective_marker`
  で主観/客観の手掛かりを添える）。**判定は意味理解を要するためコードは下さない**（候補抽出のみ）。
