# consistency_checklist.md — 整合性QA

書込許可: qa（このファイル自体は editor 管轄。qa は qa/reports/ のみ書込可）。
TIER: 1（常時参照）。

## 判定区分

- **Blocker**: canon 登録不可。修正必須。
- **Major**: canon 登録前に修正推奨。修正しない場合は editor 承認が必要。
- **Minor**: 記録のみ。次話以降で改善。
- **Warning**: 蓄積で Major に昇格する要注意事項。

## チェック項目

### C-1. 理（ことわり）関連

- [ ] 理を破る事象が「破れた」まま残っていないか（[[invariants]] I-1）→ 残っていれば **Blocker**
- [ ] 理に触れた行為に対して、対価が明示または示唆されているか → 欠落なら **Major**
- [ ] 「理の外側」を示唆する描写は、内側からの別解釈の余地を残しているか → 一意に外側と読める描写は **Blocker**

### C-2. 魔法のコスト

- [ ] 発動した魔法にコスト（詠唱／触媒／自己資源）が描写されているか（I-2）→ 完全無コストは **Blocker**
- [ ] 血統設定に反する強度の魔法を、根拠なく行使していないか（I-3）→ 根拠なしは **Major**

### C-3. ステータスの可視範囲

- [ ] ステータスを現地人に「見せている」描写がある場合、代償が設定されているか（I-4）→ なしは **Blocker**
- [ ] 現地人がステータスの存在を認識している描写になっていないか → 認識描写があれば **Major**
- [ ] 転生者が他転生者のステータスを読むシーンに、制約とコストが働いているか → なしは **Major**

### C-4. 転生者の同定

- [ ] 転生者を確実に見分ける手段を、代償なしに使っていないか（I-5）→ 無償同定は **Major**

### C-5. 死と身体

- [ ] 致死級のダメージを数値だけで無効化していないか（I-6）→ Blocker
- [ ] 死からの復活を、この世界のルール内で描いていないか → Blocker

### C-6. 情報の非対称性

- [ ] 秘密の断片を得た者に「失ったもの」が対応しているか（I-7、[[drama_invariants]] I-D5）→ なしは **Blocker**
- [ ] 「知ってしまった」ことの不可逆性が保持されているか → 巻き戻しは **Major**

### C-7. 対立ウェブ

- [ ] 転生者同士の非両立関係が、話し合いで安易に解消されていないか（[[conflict_web]]、I-D6）→ 解消は **Major**
- [ ] 三者同盟（全員が救われるルート）を許容していないか → 許容は **Blocker**

### C-8. 命名・設定の一貫性

- [ ] 過去話・canon/quick_ref.md との名称・設定差異はないか → 差異は **Major**
- [ ] specs/reference の詳細ロアとの矛盾はないか → 矛盾は **Minor〜Major**

### C-9. 数値検査（status_delta の照合）

status_delta メタブロック（[[writer]] 参照）に対して以下を検査する。canon/status.yaml と本文の両方を突き合わせる。

- [ ] **C-9.1 cause の実在**: 各 delta の `cause` に対応する事象が本文に描かれているか
  - 描写がない・不明瞭 → **Major**（理由なき数値変動）
- [ ] **C-9.2 魔法発動 → MP 消費強制（I-2）**: 本文に魔法の発動描写があるのに、対応する mp 消費 delta が無い
  - 無い → **Major**（無コスト魔法禁止）
- [ ] **C-9.3 [0, max] 範囲**: delta 適用**後**の hp/mp が [0, canon の max] に収まるか
  - はみ出す量を editor が黙ってクリップしていないか（クリップ発生時は QA レポートに明記）
  - max を超える回復・0 未満の HP は原則発生させない
- [ ] **C-9.4 死は死（I-6, I-1）**: hp.cur が delta 適用後 0 になる話で、対価なしの回復・蘇生描写がないか
  - 対価なしの回復・蘇生 → **Blocker**
- [ ] **C-9.5 変化量の妥当性**: 変化量が本文の事象規模に見合うか
  - 「かすり傷」で hp -15、「軽い呪文」で mp -8 のような不相応な急変 → **Warning**
- [ ] **C-9.6 char キーの正当性**: `char` は canon/status.yaml に存在するキャラのみか
  - 存在しない現地人・未登録キャラに数値を割り当てていないか → **Blocker**（I-4 違反）
- [ ] **C-9.7 現地人前での数値露出**: 本文で現地人の面前に数値を「言葉／表示」として出していないか（I-4）
  - 心の中の内語・転生者間の会話は可
  - 現地人前に晒す描写 → **Major**（対価が描かれていれば Minor）
